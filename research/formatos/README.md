# Formatos de referência — estrutura de episódios

Fichas técnicas das séries de referência: como é cada episódio por dentro
(tempos, atos, beats) e como se adapta ao OS LESADOS (takes, timecodes,
pipeline). Objetivo declarado do autor: **REPLICAR EXATAMENTE** as técnicas.

## Fichas

- `PTSD-completo.md` — dossiê único do PTSD (projeto, medição plano a
  plano, técnicas, gramática de cena). Formato de referência principal.
- `bobs-burgers.md` — fracasso encadeado em família, finale em festa.
- `formato-os-lesados.md` — **a nossa versão**: gramática PTSD com
  8–10 takes por episódio (a aplicar no gerador).

## Adaptação (comum a todas)

- `adaptacao-os-lesados.md` — tabela de conversão: minuto americano →
  take/timecode nosso; o que mapear para Guião/Pipeline/Video.
- `tecnicas-replicar.md` — checklist das técnicas a copiar tal e qual,
  com estado (por fazer / feito).
