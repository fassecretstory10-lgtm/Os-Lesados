# OS LESADOS · Temporada 1

Arquivo editorial da temporada, organizado por episódio. Cada episódio tem o seu próprio ficheiro Markdown.

## Estados editoriais

- **Guião em desenvolvimento / por aprovar:** pode ser preparado na Decupagem como ponto de partida, mas continua a precisar de aprovação narrativa.
- **História-base / conceito / ficha:** é material de desenvolvimento, não um guião final. A estrutura visual inicial é apenas um rascunho para rever na Decupagem.
- **Decupagem obrigatória:** cada episódio tem de passar por revisão e aprovação de cenas/planos antes de desbloquear o Pipeline.
- **Aprovação visual:** cada plano gera uma imagem separada. A imagem só fica disponível na aba **Video** depois de ser aprovada no Pipeline. A aprovação visual é independente da aprovação narrativa e da decupagem.

## Fluxo de trabalho pretendido

1. Consultar e editar o texto completo do episódio.
2. Enviar o episódio para **Guião/Pipeline**.
3. Rever a estrutura cena a cena e gerar uma imagem por cena.
4. Aprovar ou rejeitar cada imagem individualmente.
5. As cenas com imagem aprovada passam a mostrar o respetivo prompt de animação na aba **Video**.

Os episódios identificados como fichas ou conceitos permanecem explicitamente assinalados como material incompleto. Não devem ser tratados como guiões finais.
