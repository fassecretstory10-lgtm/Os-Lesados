## Premissa
Capitão Gancho e Tininha enfrentam uma queda continuada de audiências. Tininha tenta justificar os números com explicações institucionais, enquanto o Capitão exige resultados. No final, corta-se para o escritório secreto de Teresa, que faz uma chamada e diz: “A transferência vai chegar.” A sugestão é que Teresa está a manipular as audiências, sem explicar o mecanismo.

## Diálogo-base
- CAPITÃO GANCHO: “As audiências voltaram a cair.”
- TININHA: “É uma oscilação perfeitamente normal.”
- CAPITÃO GANCHO: “Há três semanas que oscila sempre para baixo.”
- CAPITÃO GANCHO: “Não quero uma apresentação. Quero audiências.”
- TERESA: “Estou? Sim. A transferência vai chegar.”
